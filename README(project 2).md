# Project 2: Iris Dataset Classification

This repository contains a Python-based Machine Learning project developed as part of the **DecodeLabs AI Intern Track**. The script trains, evaluates, and compares two different classification algorithms to determine the species of an Iris flower based on its physical measurements.

---

##  Features & Functionality

* Data Utilization: Automatically loads and processes the classic Iris flower dataset (featuring Sepal/Petal lengths and widths).
* Algorithm Comparison: Trains and evaluates both Logistic Regression and Decision Tree classifiers side-by-side.
* Smart Model Deployment: Evaluates accuracy scores dynamically and automatically deploys the higher-performing model for live inference.
* Live Interactive Inference: Includes a terminal/console input feature that allows users to supply custom flower dimensions and receive a live classification prediction (`SETOSA`, `VERSICOLOR`, or `VIRGINICA`).
